Anaconda is the recomended way to install these. Below are their pip commands or if they are avaliable in Anaconda.

chromadb
    anaconda
    pip install chromadb
gradio  - version 6 or later. 5 will not work due to how the messages get passed and read from the user to the LLM.
    anaconda
    pip install gradio
langchain
    anaconda
    pip install langchain
langchain-community
    anaconda
    pip install langchain-community
langchain-chroma
    pip install langchain-chroma
langchain-core
    pip install langchain-core
langchain-text-splitters
    pip install langchain-text-splitters
langchain-ollama
    pip install langchain-ollama
langchain-unstructured
    pip install langchain-unstructured
Markdown
    pip install Markdown
ollama
    https://ollama.com/download (for Ollama server)
        Don't forget to install a language model: https://ollama.com/library
        Don't forget to install an embedding model: https://ollama.com/search?c=embedding
    pip install ollama (for python library)
pdfplumber
    pip install pdfplumber
rand_bm25
    pip install rank-bm25
toml
    anaconda
    pip install toml
unstructured
    pip install "unstructured[all-docs]"
        note this may have additional dependencies depending on how you want to install it. Recommended way is the above pip command
        https://pypi.org/project/unstructured/ for more information
